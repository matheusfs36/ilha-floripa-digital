## Public / private boundary

This repository records stable public concepts, reproducible experiments and collaboration protocols.

Credentials, private data, restricted/licensed assets, machine-specific configuration, large generated data and unstable internal TDZ automation remain outside the public surface.

## Current design thesis

**Florianópolis is not only the scenario. Florianópolis helps create the world.**

The intended loop is:

```text
real place → human capture / story → AI-assisted interpretation → review → digital world → new experience → real place
```

The project is early R&D. Documents describe direction and research targets, not a claim that every described feature is already implemented.
